# Lythrum

Экспериментальный Wayland-композитор на Go с **бесконечным 2D-холстом**
вместо классического рабочего стола: окна, виджеты и карточки живут на
плоскости, камера летает и зумится (Chrome OS Flex / Figma-стиль),
магнитные направляющие выравнивают окна на любом масштабе.

Написан в учебных целях: чистая архитектура на событийной шине,
отказоустойчивость через Supervisor'а, ноль зависимостей на CGO-бэкендах
в headless-режиме.

## Ключевые свойства

- **Бесконечный холст** — панорамирование, зум до 8×, кольцо фокуса
  с плавным подлётом камеры, тайлинг в доли видимой области.
- **Отказоустойчивость** — каждая подсистема (обои, звук, виджеты, дисплей)
  живёт в своей горутине под Supervisor'ом: паника или крах CDP-процесса
  → экспоненциальный backoff-рестарт; ядро не падает никогда.
- **Единственный владелец состояния** — canvas.State обслуживает только
  main loop; подсистемы общаются событиями шины (неблокирующая публикация).
- **HTML5-виджеты** — каждый виджет в своём headless Chromium (CDP over
  WebSocket, pure Go); IPC с токенами, закрытым белым списком команд и
  правами (notify / canvas_write / fs_read).
- **Сессия живёт в JSON** — атомарные автосейвы (tmp+rename) каждые 10 с;
  битый файл — диагностируемая ошибка, а не потерянный вечер.
- **Звук** — схема Chrome OS Flex (click/error/notify/device/power),
  декодирование WAV/OGG pure-Go, вывод через внешний плеер
  (paplay/pw-play/aplay) с программной громкостью и mute.
- **Кадр** — программная растеризация состояния (фон, сетка, окна, виджеты,
  карточки, направляющие; шрифт Geologica) для скриншотов и headless-вывода.

## Горячие клавиши (Windows 11 / KDE Plasma)

| Клавиши | Действие |
|---|---|
| Meta + мышь / тач | панорамирование холста |
| Meta + колёсо | зум к точке |
| Meta (одиночный) | сброс камеры |
| Meta / Alt + Tab | кольцо фокуса |
| Meta + Стрелки | тайлинг окна |
| Meta + D | свернуть все |
| Alt + F4 | закрыть окно |
| Meta + I | Control Center (громкость, mute, порог снапа, акцент темы) |
| Ctrl + Shift + Esc | диспетчер задач (статусы модулей) |
| Meta + V | история буфера обмена |
| PrintScreen | скриншот кадра (PNG) |
| Power | оверлей питания |
| Caps Lock / Meta + Пробел | переключение Ru/En |
| Meta + L | блокировка сессии (SDDM) |
| Meta + E | проводник (xdg-open) |
| Стрелки / Enter / Esc | навигация открытым оверлеем |

## Сборка и запуск

```bash
go build ./...          # headless-режим собирается без внешних зависимостей
go run ./cmd/lythrum    # виртуальный дисплей 1920×1080
```

### С Wayland-сервером

Нужны `wayland-scanner`, `pkg-config wayland-server`, `libxkbcommon`:

```bash
go build -tags wayland ./cmd/lythrum
```

### Сессия SDDM

```bash
sudo ./packaging/install-sddm.sh   # бинарник → /usr/local/bin, сессия → wayland-sessions
```

После установки «Lythrum» появляется в выборе сессий на экране входа.
Пока вывод на экран не реализован (см. ARCHITECTURE.md, «Отложено»),
сессия работает вслепую: ядро, события и сессия живы, но экран чёрный.
Возврат в SDDM — Ctrl+Alt+F1…F7.

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `LYTHRUM_SESSION` | путь файла сессии (по умолчанию `~/.config/lythrum/session.json`) |
| `LYTHRUM_WALLPAPER` | обои: GIF / картинка / видео (ffmpeg) / shader |
| `LYTHRUM_ASSETS` | каталог ресурсов (шрифты, звуки) |
| `LYTHRUM_SHOTS` | каталог скриншотов (по умолчанию `~/Pictures`) |
| `LYTHRUM_BROWSER` | путь к Chromium/Electron для виджетов |

## Тесты

```bash
go test ./... -race -count=1        # весь набор с детектором гонок
go test -bench . ./internal/render/ # бенчмарки куллинга
```

Интеграционные тесты идут headless: клавиатура → шина → ядро → холст —
полный цикл без дисплея. Спецификация и карта пакетов —
[ARCHITECTURE.md](ARCHITECTURE.md).

## Статус

Реализованы 7 спринтов: базовое ядро, ввод и хоткеи, медиа/звук/контекст,
DND и HTML5-виджеты, оптимизация и Control Center, финализация (кадр,
оверлеи, watchdog), текстовый ввод (поиск/запуск) и IPC-транспорт
виджетов. Отложено: выбор области снипа, backlight, вывод поверхностей
Wayland — см. «Отложено» в ARCHITECTURE.md.
